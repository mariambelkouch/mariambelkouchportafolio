# Mariam Belkouch — Portfolio

Typography-first portfolio website for GitHub Pages.

## Run locally
Open `index.html` in a browser, or use any static-file server.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save.

## Before publishing
- Replace `YOUR_EMAIL@example.com`.
- Replace `YOUR-LINKEDIN` with the actual LinkedIn profile slug.
- Review all metrics and confidential language.
